# 04 — API Contracts (v1, draft)

Base path: `/api/v1`. JSON. Money and quantities are **strings** holding decimals. IDs are UUIDv7.
The OpenAPI document will be generated by FastAPI from these contracts in Stage 2.

## Conventions

* **Auth:** `Authorization: Bearer <access token>`; refresh through an HttpOnly cookie at `POST /auth/refresh`.
* **Branch scope** comes from the token. A `branch_id` in the body is ignored or rejected.
* **Writes that post business effects** require the header `Idempotency-Key: <uuid>`. A replay with the same key and body returns the original response (`200`, header `Idempotent-Replay: true`). The same key with a different body returns `409`.
* **Optimistic concurrency** for master data: `If-Match: <version>`; a mismatch returns `409` with the current version and a conflict payload.
* **Pagination:** `?limit=50&cursor=<opaque>` → `{ "items": [...], "next_cursor": "..." }`.
* **Errors** follow RFC 9457 problem details:
```json
{ "type": "https://errors.app/insufficient-stock", "title": "Insufficient stock",
  "status": 422, "detail": "Beef: requested 15000 g, available 12000 g",
  "code": "INSUFFICIENT_STOCK", "fields": {"lines[0].quantity": "exceeds available"} }
```

## Endpoints

### Identity
| Method | Path | Permission |
|---|---|---|
| POST | `/auth/login` (password, optional TOTP) | public, rate-limited |
| POST | `/auth/refresh`, `/auth/logout` | session |
| POST | `/auth/pin-switch` (shared tablet) | device session |
| GET | `/me` (user, branch, permissions) | session |

### Ingredients & recipes
| Method | Path | Permission |
|---|---|---|
| GET/POST | `/ingredients` (`?q=` search, `?active=`) | `ingredient.read` / `ingredient.write` |
| GET/PATCH | `/ingredients/{id}` (If-Match) | |
| GET | `/ingredients/{id}/price-history` | `ingredient.read` |
| POST | `/ingredients/{id}/conversions` | `ingredient.write` |
| GET/POST | `/recipes`, `/recipes/{id}/versions` | `recipe.read` / `recipe.write` |
| POST | `/recipes/{id}/versions/{v}/approve` · `/publish` | `recipe.approve` / `recipe.publish` |
| GET | `/recipes/{id}/versions/{v}/cost` (cost basis: CURRENT) | `recipe.read` |
| POST | `/recipes/cost-preview` (unsaved draft) | `recipe.write` |

`GET /recipes/{id}/versions/{v}/cost` response:
```json
{ "cost_basis": "current", "currency": "UGX", "computed_at": "2026-11-21T09:00:00Z",
  "batch_cost": "92000.0000", "cost_per_portion": "4600.0000",
  "target_food_cost_rate": "0.300000", "recommended_price": "15333.3333",
  "selling_price": "15000.0000", "food_cost_rate": "0.306667",
  "gross_contribution": "10400.0000", "exceeds_target": true,
  "lines": [{ "ingredient_id": "…", "gross_base_quantity": "5000", "base_unit": "g", "cost": "90000.0000" }] }
```

### Inventory
| Method | Path | Permission |
|---|---|---|
| GET | `/stock` (on hand, value [FIFO], below minimum) | `stock.read` |
| GET | `/stock/{ingredient_id}/batches` · `/movements` | `stock.read` |
| POST | `/stock/consumptions` **(Idempotency-Key)** `{lines:[{ingredient_id, quantity, unit}], note, override?:{reason}}` | `stock.consume` (+`stock.override`) |
| POST | `/production-runs` **(Idempotency-Key)** `{recipe_version_id, batches, actual_portions?}` | `production.record` |
| POST | `/stock/adjustments` **(Idempotency-Key)** `{ingredient_id, quantity, unit, reason, note}` | `stock.adjust` |
| POST | `/stock/movements/{id}/reverse` | `stock.reverse` |
| POST/GET | `/stock-counts`, PUT `/stock-counts/{id}/lines`, POST `/stock-counts/{id}/approve` | `stock.count` / `stock.count.approve` |

`POST /stock/consumptions` → `201` (cost basis: FIFO actual):
```json
{ "movement_id": "…", "cost_basis": "fifo",
  "lines": [{ "ingredient_id": "…", "quantity": "15000", "base_unit": "g", "total_cost": "145.0000",
              "allocations": [{ "batch_id": "A", "quantity": "10000", "unit_cost": "0.00900000" },
                              { "batch_id": "B", "quantity": "5000",  "unit_cost": "0.01100000" }] }] }
```

### Dashboard & reports
| Method | Path | Notes |
|---|---|---|
| GET | `/dashboard` | inventory value (FIFO), month purchases, payables, low stock, recent purchases, price increases, recipes over target (current), consumption (FIFO). Each figure carries `cost_basis` and `as_of`. |
